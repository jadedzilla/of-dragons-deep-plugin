# Of Dragons Deep (Dalamud plugin)

Dalamud plugin that exports the player's caught fish and fishing achievements to the Of Dragons Deep tracker
(https://ofdragonsdeep.jadedzilla.com/, repo jadedzilla/of-dragons-deep). See README.md for how it works,
building and releasing.
